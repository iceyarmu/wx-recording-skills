# 内容与风格规范

把原始材料整理成清楚、自然、有视觉解释力的纪要。主体记录材料中的具体内容，不扩写成泛泛的分析文章或评审报告。目标是保留值得记住的内容，让读者更快理解其关系，而不是将所有输入套入同一种文章或组件模板。

## 内容组织

- 先判断材料的表达目的：解释、记录经过、比较方案、形成决定、提出构想或表达感受。混合材料按主线组织，保留必要支线。
- 从内容中提取章节，不预设章节数量、固定提纲或固定收尾。每节回答一个读者真正需要了解的问题；长材料可以分部并包含小节，短材料可以不分部。
- 保留解释结论所需的背景、关键细节、条件与因果。简洁以每个信息块的有效信息衡量，不以全文越短越好衡量；不要删掉具体机制和例证，只剩概括性议论。对结论有用的对象、数据、阈值、范围、行为与结果，应在正文或图解中有明确落点，不能统称为“相关情况”或“仍需验证”。
- 标题直接点出对象、变化或问题；导语交代最重要的背景与看点。章节标签用于定位，标题用于表达，不重复编号和意思。标题只留中心对象与关键判断，将背景、解释和限定移入内容；图中节点采用短标签加必要的一句说明，不放缩小字号的整段议论。
- 先安排信息，再选择图形。图前文字提供理解背景，图形呈现关系，图后只补充必要解释，不将同一内容讲三遍。
- 结尾服从材料：可以是决定、行动、未决问题、感受，也可以自然结束。不要为了完整感补造建议或金句。重复出现的同一机制或主张归并到最合适的小节，不再在末尾以“共同标准”“执行方法”等新栏目重述。

## 语言与语气

- 每个信息块先给结论或关键事实，再补必要依据、条件或后果。短段落只承担一个任务；并列要点用短列表、标签组或对照项，不用连接词串成长段。
- 使用具体对象、动作与短句，保留说话人的表达特点、有效比喻和情绪；去掉口头填充、主持串词及无意义重复。引用选取完整、有辨识度的原句片段，不为保留口语感大段引用重复和结巴。
- 能直接说清的内容，删去“讨论中提到”“一个例子是”等转述外壳；只有归属影响判断时才保留主体。标题也优先短而明确，避免连串设问、铺垫和抽象口号。
- 写完后做一次压缩：删除不改变事实、关系、立场或行动的句子。图解已承担的步骤、分类和比较，正文不再逐项复述；同样的提醒不在多节反复补充。
- 正文直接讲事情，不点评材料如何叙述，也不展示内部编辑步骤或审稿意见。
- 信息层级靠标题、段落、加粗和图形共同建立；不靠反复贴“归纳”“洞察”等标签制造重点。
- 不机械要求每节都有结论框。确有新的理解、限制或行动抓手时，才用短句突出。
- 引号内使用原话，并保留材料已有的归属。改写后的句子不伪装成引文。

## 忠实与不确定性

- 区分事实陈述、个人判断、设想、决定和新增分析。标注应足以避免误读，不应打断整篇阅读。
- 保留条件、否定、程度、时序、主体和因果方向。不能以表达更顺、更有冲击力或设计更合理为由改变它们。
- 对修正和反悔，识别其适用范围；以最后明确决定收束相关问题，不将局部变更扩大为全盘推翻。
- 缺失、歧义、估计和精确数值分别处理。数值映射不明时不自行分配、取中值或推算固定总量；仍可展示不依赖该数值的关系。
- 重要限定紧邻相应主张，同一限定不反复出现。一般来源范围可放短注或折叠说明；不能把影响理解的限制藏起来。
- 对明确的项目决定无需附新闻式免责声明。外部断言保留归属；需要查证时区分核实结果与原文说法。共同来源范围集中说明一次；局部用简短归属或限定，不为每次个人体验附上“不代表所有人”的完整声明，也不因缺乏外部核验把明确意见改成未决事项。
- “未决”用于材料明确留下的问题或尚未解决的冲突，不是所有未上线、未测试方案的默认标签。用一次“设想”说明性质即可展开内容；不要反复补“不是已定规则”，也不要自动生成待验证问题清单。
- 示例和参考成品用于学习表达方法，不是事实来源，也不是待输出的标准答案。

## 语义到视觉的映射

选择最能揭示关系的表达；下表是判断依据，不是必须逐项使用的清单。

| 信息关系 | 可用表达 | 判断要点 |
|---|---|---|
| 时间与状态变化 | 时间线、阶段标记 | 保持时序与状态，不将技术步骤误作事件 |
| 顺序、依赖、循环 | 步骤图、连接图、回环 | 箭头必须有实际含义；并列项目不用箭头硬串 |
| 差异与取舍 | 同维度对照、并列图 | 展示决定差异的因素，不自行选定方案 |
| 空间、位置、路径 | 场景图、地图、布局示意 | 保持方向、相对位置和固定/变化部分的区别 |
| 分类、组成、资源职责 | 分组、槽位、来源与用途对照 | 不把分类画成转化关系，不混淆实体职责 |
| 数量与比例 | 数量图、条形图等 | 仅用有依据且口径可比的数据编码几何比例 |
| 定性趋势 | 简洁文字或非定量示意 | 不用任意长度暗示精确倍数 |
| 操作与反馈 | 小型交互演示 | 用户动作必须改变所解释的状态，而非仅改装饰 |

不能提供比文字更清楚的理解时，不必画图。图表数量、种类和尺寸由内容决定，不为丰富页面而增加图形。

## 可见的信息分组

- 内容层级应能直接看出来。多主题长文可用分部标题统领若干小节，小节用独立卡片承载；短文不必增加分部。不要把所有话题铺成同一级、同一种长文本卡片。
- 一个包围框表达一个相关信息组。组合图解可用浅底、细边框与内边距，把标题、节点、连线、控件和图注收在同一视觉区域；内部节点再按关系分组，避免图形零散漂在正文中。
- 外层主题卡、内层图解区、节点要有主次：用留白、底色或边框区分，不层层加重边框和阴影。纯文字小节无需为了整齐硬塞图框。
- 结构随信息关系变化：流程突出连接，取舍并列，组成分组，结论短条收束。多种结构共享字体、间距和圆角；不把结构一致误解为所有内容都用同一布局。

## 配色的职责

- 中性底色与正文保证阅读，主色建立页面识别，辅助色区分有意义的主题、分支或状态。材料包含多类关系时，应让它们有清楚的色彩区别，不把所有标签、节点、提示都染成同一主色。
- 先分配色彩职责，再配色。同类元素保持同色；主题分类用不同辅助色，正负、提醒等状态色只用于相应语义。不要用每节随机换色来制造丰富。
- 颜色集中在短标签、节点标题、关键数字、图形、细边线与浅底容器上，长段正文保持高可读性。一个彩色信息块配套前景色、浅底色和边线色，而非只改文字颜色。辅助色应真正落到相关图解或信息块中，不能仅在样式表中声明、只染章节小字，主体仍全部使用主色。
- 只启用当前内容需要的色彩角色，不规定色数或色相。深色模式保留区分与对比度，含义同时通过文字、形状或位置表达。

## 视觉趣味与阅读节奏

- 使用与题材相关、能帮助识别对象或理解关系的具象细节。趣味来自内容的可感知表达，而不是套用固定图标、装饰或配色。
- 根据重要性分配视觉面积：核心关系可以成为主图，辅助线索宜轻量。避免所有图都缩成小图标，也避免装饰压过信息。
- 页面保持统一的字体、色彩、边距与层级；内部布局随语义变化，不要求所有章节都是相同卡片。
- 选择适合材料语气的主题色，兼顾深浅色的对比度。参考配色是起点，不是按行业绑定的规则。
- 示意性细节可以帮助理解，但应与真实数据、正式设计和已发生事件区分。装饰数量不承担未经说明的数据含义。
- 动画与交互仅用于表现变化、比较状态或揭示细节；不要持续抢占注意力。手机上仍应清楚可读、可操作。

## 输出前复核

先只看标题与信息块，检查能否扫出主线、分组和关键结论；再检查每段是否有新增信息、能否删除转述外壳与重复限定。检查图文是否互补、图解是否形成完整区域、色彩是否有明确职责、原话特点与关系是否保留。对交互核查状态与计算，对引文核查原始输入。修订后重新检查文档完整性，不将评审说明泄漏到正文。
